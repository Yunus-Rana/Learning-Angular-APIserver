# Learning-Angular-APIserver

A lightweight mock REST API built with JSON Server for Angular learning projects and frontend development practice.

## About
This project provides sample user data that can be consumed in Angular applications for CRUD examples, form handling, table rendering, and API integration tutorials. It is designed to be simple, fast, and easy to run locally for learning and experimentation.

## Features
- Mock REST API using JSON Server
- Preloaded sample user records
- Support for common CRUD operations
- Easy setup for Angular frontend demos
- Ideal for learning API integration and data binding

## Getting Started
### Install dependencies
```bash
npm install
```

### Start the API server
```bash
npx json-server --watch db.json --port 3000
```

The API will be available at:
```bash
http://localhost:3000
```

### Example endpoint
```bash
http://localhost:3000/user_1
```

## Project Structure
```text
APIserver/
├── .gitignore
├── db.json
├── package-lock.json
├── package.json
├── README.md
```

`node_modules/` is generated by `npm install` and is intentionally excluded from Git. Keep `package-lock.json` tracked so installs use consistent dependency versions.
